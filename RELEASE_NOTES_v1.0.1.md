# Tool Launcher 1.0.1

Tool Launcher 1.0.1 is the first maintenance update for the public release.

## Fixed

- Fully localized the Add App and Add Category dialogs in all 16 interface languages.
- Removed the English `NEW` default category name. New categories now start with an empty field and a localized placeholder.
- Corrected several launcher interaction, layout, drag-and-drop, and settings behaviors discovered during final real-world use.

## Improved

- Expanded and refined the AI Background Generator workflow, scene library, image handling, and local upscaling feedback.
- Improved launcher defaults, category handling, dashboard sizing, and visual consistency.

## Installation

Download `Tool.Launcher.Setup.1.0.1.exe` and run the installer. It can be installed over Version 1.0.0. Existing launcher data and settings are retained.

The installer is not digitally signed, so Windows SmartScreen may display an unknown-publisher warning.
