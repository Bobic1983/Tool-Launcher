# Tool Launcher 1.0.3

Tool Launcher 1.0.3 focuses on three practical generator improvements.

## Highlights

- Text scaling directly in the generators.
- Local ChatGPT app integration.
- Visual feedback when a prompt text has been copied.

## Languages and Validation

- Updated and validated all 16 interface languages.
- All locale files contain the same 840 translation keys.
- Production build and TypeScript validation completed successfully.

## Installation

Download `Tool Launcher Setup 1.0.3.exe` and run the installer. It can be installed over an earlier Tool Launcher version. Existing launcher data and settings are retained.

The installer is not digitally signed, so Windows SmartScreen may display an unknown-publisher warning.
