# Tool Launcher 1.0.4

Tool Launcher 1.0.4 is a small bugfix and usability update.

## Highlights

- Fixed Windows startup in tray when minimizing and closing to tray are disabled.
- Added app arrangement mode in Settings under Appearance > Apps.
- Free arrangement keeps apps on the selected grid field, including empty spaces.
- Sorted arrangement keeps the compact automatic app layout.

## Languages and Validation

- Updated and validated all 16 interface languages.
- All locale files contain the same 844 translation keys.
- Production build and TypeScript validation completed successfully.

## Installation

Download `Tool Launcher Setup 1.0.4.exe` and run the installer. It can be installed over an earlier Tool Launcher version. Existing launcher data and settings are retained.

The installer is not digitally signed, so Windows SmartScreen may display an unknown-publisher warning.
