# Tool Launcher 1.0.2

Tool Launcher 1.0.2 is a major interface and workflow refinement update focused on the AI generators, multilingual usability, responsive layouts, and theme consistency.

## Highlights

- Reworked the AI Icon Generator and AI Banner Generator with clearer guided workflows, larger previews, improved controls, and direct prompt handoff to ChatGPT or Gemini.
- Expanded and polished the AI Background Generator with richer scene, style, mood, composition, and refinement choices.
- Added context-sensitive tooltips and dedicated toolbox panels across the generator workflow, with clearer guidance for controls, creative choices, and their visual effects.
- Added improved image import, preview, save, apply, and local upscaling workflows.
- Refined Settings and the Custom, Steam, GOG Galaxy, and Razer Cortex theme presets.

## Improved

- Improved layouts for notebooks, 4:3 displays, high-DPI scaling, and smaller resolutions.
- Increased readability throughout generator dialogs, application selection, Add App, Add Category, settings, sliders, toggles, buttons, and explanatory text.
- Improved default icon composition, logo positioning, text positioning, and preset presentation.
- Refined launcher category, application, context-menu, dashboard, and background behavior.

## Languages

- Updated and validated all 16 interface languages.
- Fixed clipped, colliding, untranslated, and inconsistently sized labels, including long Russian, Ukrainian, French, Spanish, and Italian text.
- All locale files contain the same 807 translation keys.

## Installation

Download `Tool Launcher Setup 1.0.2.exe` and run the installer. It can be installed over an earlier Tool Launcher version. Existing launcher data and settings are retained.

The installer is not digitally signed, so Windows SmartScreen may display an unknown-publisher warning.
